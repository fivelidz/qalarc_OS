### AI/ML
```bash
oterm                    # Launch AI chat TUI
ollama run llama3.2:1b  # Run model directly
llama-cli -m model.gguf # Use llama.cpp
```

### Development
```bash
code                    # VSCode

lazydocker              # Docker TUI
```

```bash
btop                    # System monitor
nvtop                   # GPU monitor
rocm-smi                # AMD GPU stats
```

### Containers
```bash
docker ps               # List containers
podman                  # Alternative to docker
dive image:tag          # Explore image layers
```
