## 🎯 Quick Start Path

**New to Qalarc AI-OS?** Follow this learning path:

### Day 1: Getting Comfortable
1. Read [GETTING_STARTED.md](./GETTING_STARTED.md) (20 min)
2. Explore the desktop, open some apps
3. Connect to WiFi, browse the web
4. Practice 5 essential keyboard shortcuts

### Day 2: Try AI
1. Read [AI_CODING_TUTORIAL.md](./AI_CODING_TUTORIAL.md) first section (10 min)
2. Download your first model (see [OLLAMA_MODELS_GUIDE.md](./OLLAMA_MODELS_GUIDE.md))
3. Try "Open in AI" on any folder
4. Ask the AI to explain something simple

### Day 3: Get Efficient
1. Read [KEYBOARD_SHORTCUTS.md](./KEYBOARD_SHORTCUTS.md) (10 min)
2. Print the cheat sheet
3. Practice using TMUX
4. Learn 5 more shortcuts

### Week 2+: Explore Advanced Features
- Try different AI models
- Learn TMUX workspace
- Customize your desktop
- Create your first project with AI help

## 🆘 Getting Help

**Still need help after reading the guides?**

1. **Built-in help system:**
   ```bash
   qalarc-explain
   ```
   Interactive menu with tutorials and tips

2. **Documentation location:**
   ```
   ~/qalarc_OS/docs/
   ```
   All guides are here in Markdown format

3. **Community support:**
   - Qalarc forums: https://qalarc.com/community
   - Email: team@qalarc.com
   - Matrix chat: #qalarc-os:matrix.org

4. **When asking for help, include:**
   - What guide you were following
   - What step you're on
   - What error you're seeing
   - What you expected to happen
