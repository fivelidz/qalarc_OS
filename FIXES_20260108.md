# Fixes Applied - January 8, 2026

## Summary

Previous agent sessions incorrectly disabled several critical features claiming they "weren't available" in NixOS 25.05. This document records what was broken and how it was fixed.

---

## Issue 1: Ollama ROCm Acceleration Disabled

### What Was Broken
- Commit `68b4867` commented out ROCm support claiming "not supported in nixpkgs 25.05"
- Ollama was running on CPU only (defeating the purpose of an AI workstation with GPU)

### Root Cause
The agent didn't understand the API change. The `acceleration = "rocm"` option was deprecated in favor of using specific packages.

### The Fix
```nix
# OLD (deprecated):
services.ollama = {
  enable = true;
  acceleration = "rocm";  # This option was removed
};

# NEW (correct):
services.ollama = {
  enable = true;
  package = pkgs.ollama-rocm;  # Use the ROCm-enabled package directly
};
```

### Verification
```bash
nix eval .#nixosConfigurations.gmktec-01-single-drive.config.services.ollama.package.meta.description
# Output: "Get up and running with large language models locally, using ROCm for AMD GPU acceleration"
```

## Issue 3: grub-btrfs Not Available

### What Was Broken
- Commit `79189b2` commented out grub-btrfs claiming "not available in nixpkgs 25.05 stable"
- BTRFS snapshots weren't showing in GRUB boot menu
- User couldn't boot into previous snapshots

### Root Cause
The agent was partially correct - grub-btrfs genuinely isn't packaged in nixpkgs. However, the solution shouldn't have been to just disable it.

### The Fix
Created a custom package at `packages/grub-btrfs/default.nix`:
- Fetches from upstream GitHub (v4.14)
- Wraps scripts with proper PATH
- Installs systemd service for automatic GRUB updates
- Integrates with snapper module

### Verification
```bash
nix flake check  # Passes without errors
```

## Issue 4: CachyOS Kernel "Source Build" Confusion

### What Was Broken
User was told "CachyOS kernel requires source builds and fails"

### Root Cause
Miscommunication. The CachyOS kernel from `chaotic-nyx` uses a **binary cache**. It doesn't require source compilation.

### The Fix
No code change needed - the configuration was correct. Changes were stashed/dropped.

The flake.nix correctly has:
```nix
chaotic.url = "github:chaotic-cx/nyx/nyxpkgs-unstable";  # Binary cache
chaotic.nixosModules.default  # Enables the overlay
```

And host configs correctly use:
```nix
kernelPackages = pkgs.linuxPackages_cachyos;  # Pre-built from cache
```

## Lessons for Future Agents

### DO:
1. Check if a package exists under a different name (`ollama-rocm` vs `acceleration = "rocm"`)
2. Check binary caches (chaotic-nyx, cachix) before assuming source builds
3. Create custom packages for missing software
4. Understand deprecation → replacement paths

### DON'T:
1. Comment out features just because you hit an error
2. Assume "not available" without checking alternatives
3. Remove working functionality without approval
4. Take error messages at face value without investigation
